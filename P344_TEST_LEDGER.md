# P3.44 Test Ledger

## Phase

**ChatGPT Web HWPX MCP P3.44 — Autonomous Professional Document Authoring, Multi-Stage Plan→Compose→Render→Critique→Repair→Deliver, Cross-Domain Blind Evaluation & Production-Grade AuthorBench**

## Constitution

P3.44 is a bounded resumable workflow runtime, not an unbounded agent loop.

- Rust owns the production repair/delivery gate.
- TypeScript independently implements the same state machine and owns blind AuthorBench scoring.
- Python is the HWPX-native adapter/materializer and MCP binding.
- PowerShell/Windows remains Hancom-native world contact.

The default professional path requires render evidence before delivery. Missing world contact becomes `WAIT_RENDER`, never an inferred visual PASS.

## Repair law

A repair is eligible only when:
1. a diagnostic reports `NEEDS_REPAIR`;
2. a locator-bound executable repair exists;
3. the repair budget is not exhausted;
4. any organization policy gate remains PASS;
5. P3.42 preservation enforcement remains PASS.

After a post-render repair, the old render is invalidated and a new render is required.
