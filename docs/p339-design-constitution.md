# P3.39 — Design Constitution

P3.39 moves document quality authority above raw formatting primitives. The product must help an agent reason about semantic roles, editorial hierarchy, reading geometry, density, visual restraint and repair evidence before it asks for low-level XML/HWPX mutations.

## Constitution

1. **Semantic–Visual Congruence** — semantic importance must have visible consequence.
2. **Reading Geometry** — prose is aligned for reading; symmetry is secondary.
3. **Density Budget** — information-rich regions need width, padding and whitespace.
4. **Multi-Channel Hierarchy** — use more than numbering or font size alone.
5. **Narrative–Visual Agreement** — narrative order and visual prominence must agree.
6. **Restraint** — color, boxes and icons encode meaning, not decoration.
7. **Design System over Microformatting** — agents specify archetype/intent; compilers choose most raw values.
8. **Verify before Repair** — diagnose and bind repairs to evidence/locators.
9. **Evidence Layering** — static structure, render evidence and human review are distinct authorities.
10. **Tool Economy** — high-level workflows precede low-level escape hatches.

## A1 as frozen failure specimen

AuthorBench A1 is not silently repaired in this phase. Its human review is retained as evidence that native validity and static preview PASS are insufficient for professional document quality. P3.39 should detect the mechanically observable subset of those failures and explicitly identify the rest as semantic/render/human-only evidence.

## No beauty score

P3.39 does not compress visual quality into one scalar. Diagnostics are named, repairable findings with evidence and authority.
